# Make the AI Judge Laugh

One office-life joke, one line: the boss's "open-door policy" — the door
is open, but every visit costs you a project.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the line (single line, 1–199 characters, no leading or
trailing whitespace) and writes it plus a trailing newline to
`/output/entry.txt`, then reads the file back to confirm it matches.
